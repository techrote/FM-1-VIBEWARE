# VIBEWARE native Windows selector (Draft/HOLD)

This is a source-only local launcher for original Windows native instrument archives. It is NOT an FM-1 virtual-target executable, firmware installer or companion transport. Python 3.10+ is required; no pip packages. The source-only selector itself does not redistribute any instrument executable or dependencies. Download the exact original author ZIP from the manifest (GitHub login may be required). Keep the three selector files together.

Run `python selector.py` to list exact candidates and artifact URLs. Run `python selector.py chronomorph "C:\\Downloads\\chronomorph-native-Windows.zip"` (substitute the downloaded filename) to verify SHA-256, extract into a fresh temporary directory, launch its local native server and open a browser. Use Ctrl+C to terminate the server. The same command works for ecophon, xenoresonator and grimoire. All four pinned archives passed independent Windows and Linux archive/rebuild/score checks. All four packages now pin [independent QA run 46095359490](https://github.com/techrote/FM-1-VIBEWARE/actions/runs/46095359490) (8/8 PASS): corrected Xenoresonator keyboard/factory gallery, Chronomorph Lattice Variations, Ecophon whole Habitat Arc, and Grimoire Orbit Sketch JSON exchange. Newer user-material, live-score and comparative replay packages remain pending their own independent gates. No provisional override is needed. Ecophon includes Population Tide and Habitat Arc WAVs under the exact permitted nested payload paths. `--verify` checks an archive without executing it. `--probe` exercises actual local HTTP readiness without opening a browser.

No driver, external transport, hardware, flash, or virtual emulator is installed. Original archives remain separate and contain authored demos, controls, and source where provided; Grimoire's core source is linked by exact revision in the manifest. Review rights before redistribution; none authorized by this selector. Physical HOLD. Standalone native, actual virtual, companion and physical gates remain separate in compatibility.md.
