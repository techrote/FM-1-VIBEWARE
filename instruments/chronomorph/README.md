# Chronomorph — three elastic clocks (Draft/HOLD)

Original C11 24 kHz mono composition engine. Three independently accumulated sixteenth-note clocks interact through alternating four-step master warp windows (lane 0 fixed, lane 1 ±warp, lane 2 opposite half-warp). Each lane has a 1–16-step editable pattern and a nested four-cycle pitch progression; seeded ghost hits and scale-degree mutation add controlled variation. Internal triangle bass, harmonic bell and noise/triangle dust voices provide standalone sound. No heap, queue or external dependencies in core; at most three ticks per sample, immediate stop/mute, resume preserves clock phase, reset initializes seed/preset and stops. Control and render calls must be serialized by consumer. No actual MIDI output or wire protocol. Host rate not an FM-1 hardware assumption.
