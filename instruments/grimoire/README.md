# Grimoire — Orbit Gate (first rite)

Original portable fixed-point 24 kHz monophonic gesture instrument. Three phase-coupled triangular oscillators, satellite phase modulation, a bounded low-pass stage and gate envelope give three distinct material regimes (Amber, Iron, Abyss). X selects one of 24 chromatic carrier pitches; Y changes phase perturbation and filter response. Standalone core API requires no companion. The native virtual companion renders actual core PCM and displays actual oscillator phase/energy, not simulated telemetry. Pointer release decays the gate; Panic silences immediately. Local session rejects stale generations and invalid version/events. This is not a wire protocol; no actual CYD firmware is supplied here; the separate PLATFORM candidate now has virtual-target evidence.

## Build and audition

From repo root (Linux gcc; Windows MinGW gcc, use orbit.dll instead of orbit.so and omit -fPIC):

    gcc -std=c11 -O2 -Wall -Wextra -Werror -fPIC -shared instruments/grimoire/orbit.c companion/grimoire/session.c -o orbit.so
    python companion/grimoire/host.py orbit.so

Open http://127.0.0.1:8765 in a browser, click Start audio, then drag in the pad. The host is local-only and one current session is supported. Browser PCM scheduling is a virtual demonstration; no latency guarantees or hardware claim. CI builds three six-second actual-core WAV demos and tests extracted companion files. The local API has no asynchronous device queue; no production transport claim. The instrument-local fixture coalesces adjacent XY events, preserves gate edges, caps pending events at 16, panics on overflow and cancels scheduled browser audio on panic/blur. The local host expires inactive sessions after 1.5 s, rejects stale generations, and does not refresh the lease on invalid events. A blocked HTTP handler can delay expiry (1 s socket timeout); these are simulator safeguards, not physical real-time guarantees. See companion/grimoire/profile.json for the provisional semantic profile (intended enhanced or basic MIDI fallback; neither device route verified). No common CYD firmware or wire format is implemented.

## Orbit Passage — sustained gesture fixture

`performance.c` exercises the existing local session and renders an authored 12-second phrase across Amber, Iron and Abyss. Each material holds a gate while pitch and Y change, releases, then panics before the next material. The fixture checks all 128 X values per material against the 24-step pitch lattice, monotonic carrier increments, exact phase/envelope continuity at XY events, causal Y PCM differences at identical phase, silence, headroom and deterministic repetition. Build as in CI (same core and session, performance.c instead of test.c); run with an output WAV path. ## Orbit Ribbon — live trajectory shapes

Select slow, medium or fast, then explicitly hold the gate. Ribbon is the original eight-point cycle; Crown holds a bright Y register while climbing and descending in pitch; Pendulum sweeps a lower Y register with a narrower pitch excursion. The selector below the pad changes the local trajectory without resetting the clock or gate. Shape changes blend over eight reference ticks; manual XY takes priority and resumes the selected shape on release. Panic, reconnect, focus loss and overload restore the original Ribbon shape and clear automation. These are original local gesture fixtures, not new FM-1/CYD transport commands. The original C Ribbon WAV/trace fixtures and native DSP remain unchanged.

## Performer-authored Orbit Sketch
Open **Draw your own orbit** below the performance pad. Tap eight points in the desired playback order (the last point loops back to the first). Undo or clear edits only the draft; the saved path remains available. Apply is disabled until all eight points are present. Applying selects My sketch when connected; use the existing speed and explicit hold gate to hear it. Active edits blend from the current position, retain the same sample-block clock and never retrigger the gate. Apply is ignored during a performance drag or connection setup. Saved sketches remain in browser memory after panic/reconnect, but playback resets to off and the original Ribbon; they cannot replay until explicitly selected and enabled. Reload clears them. The editor is a local authored model, not device telemetry or a new wire command.

## Orbit Sketch exchange

Use Export saved sketch to populate the JSON field, copy the text, or paste a compatible document and choose Import to draft. Import validates a bounded version-1 document with exactly eight integer XY pairs in 0–127 and replaces only the draft. It never alters the sounding trajectory, gate, speed or session; Apply is a separate explicit action. Malformed, oversized and incompatible documents leave the saved path and draft unchanged. The document is a local authoring fixture, not a transport protocol or device telemetry. The exact predecessor sketch candidate passed [author native/Chromium](https://github.com/techrote/FM-1-VIBEWARE/actions/runs/46089595306) and [independent Windows/Linux QA](https://github.com/techrote/FM-1-VIBEWARE/actions/runs/46090669288); [Windows evaluator](https://github.com/techrote/FM-1-VIBEWARE/actions/runs/46089595306/artifacts/15240398166).
